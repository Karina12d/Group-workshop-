# Group Workshop – Mini Apps

Proyecto en **React + Vite + Tailwind**. Login simulado y "navegación" con renderizado condicional (sin React Navigation).

## Pantallas
- **Login** – usuario/contraseña hardcodeados: `admin` / `1234`
- **Menú** – Suma, Calculadora, API, Formulario
- **Suma** – suma de dos números
- **Calculadora** – `src/screens/Calculator.jsx` (pendiente de integrar)
- **API** – búsqueda con debounce + tarjetas + modal de detalle (Rick and Morty API)
- **Formulario** – React Hook Form + Zod (radio, select, checkbox, textarea, submit)

## Cómo correrlo
```bash
npm install
npm run dev
```
